YMM4 Selective Attributes
选择性属性复制插件
========================================

【插件简介】
本插件用于在 YMM4 中选择性复制素材属性，并将所选属性批量粘贴到其他素材。
粘贴时只修改所选属性，不替换目标素材本身。

【主要功能】
- 选择需要复制的属性
- 支持 X、Y、Z 位置参数独立选择
- 支持不透明度、缩放、旋转、音量等属性
- 支持视频效果和音频效果复制
- 支持多个目标素材批量粘贴
- 支持保存、载入和删除属性预设
- 支持撤销和重做

【使用方法】
1. 在 YMM4 中打开 Selective Attributes 插件。
2. 选择一个素材作为属性来源。
3. 勾选需要复制的属性。
4. 选择一个或多个目标素材。
5. 点击粘贴，将选中的属性应用到目标素材。

也可以保存常用属性组合为预设，以便以后快速使用。

【注意事项】
- 属性预设保存的是属性选择设置，不保存素材内容或具体动画数值。
- 粘贴操作不会替换目标素材的媒体内容。
- 建议在进行批量修改前保存工程。
